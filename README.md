# Damas da Praça

Jogo de damas feito em um único arquivo HTML, com CSS e JavaScript puro.

## Como rodar

Basta abrir o `index.html` no navegador.

## O que tem

- Partida contra o computador (fácil, médio ou difícil) ou contra outra pessoa no mesmo aparelho
- Escolha de jogar com as brancas ou com as pretas
- Captura obrigatória e promoção a dama
- Desfazer jogada e súmula com o histórico da partida
- A jogada do computador é calculada em um Web Worker, então a tela não trava
- Sons, tema claro/escuro e layout para celular
- A partida em andamento fica salva no `localStorage`
